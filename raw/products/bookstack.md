# BookStack project FAQ and roles

> Source: https://www.bookstackapp.com/about/project-faq/ ; https://www.bookstackapp.com/docs/user/roles-and-permissions/
> Collected: 2026-11-02
> Published: Unknown

The BookStack source code is distributed under the MIT license. This is an open source license which allows any type of use, modification, and distribution.

If looking to build a custom integration for your instance, our REST API is a good place to start, with our api-scripts repository holding a range of examples in various languages.

Permissions can be overridden at a Shelf, Book, Chapter or Page level where required.

Custom permissions applied to books or chapters will auto-cascade to all child content within unless that content has its custom permissions.
