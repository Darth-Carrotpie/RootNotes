# Self-host AFFiNE and Team License

> Source: https://docs.affine.pro/self-host-affine/ ; https://docs.affine.pro/self-host-affine/features/team-license
> Collected: 2026-11-02
> Published: Unknown

Install with Docker Compose, which is the recommended deployment method.

AFFiNE server | Runs the web application, API, sync, and collaboration services.
Postgres | Stores AFFiNE application data and is the primary database to back up.
Redis | Provides cache, background task, and sync infrastructure.
Blob storage | Stores uploaded images, files, and other workspace blobs.

To have more seats in your self-hosted workspace, you have to either subscribe to Team Plan or purchase a Installable Licese.
