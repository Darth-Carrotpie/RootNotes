This is the documentation for v2 of the SDK, the stable release line implementing the 2026-07-28 spec.

The Model Context Protocol (MCP) is an open standard that connects AI applications to the systems where your data and tools live. You write a server that exposes tools, resources, and prompts; any MCP host — Claude Code, VS Code, Cursor, your own application — connects to it and lets a model use them.
