# RootNotes

RootNotes is a planned self-hosted workspace for human notes and agent-maintained project knowledge. Each repository gets a project workspace; reusable rules and skills live at broader scopes. The web app, API, and MCP server will share one permission and versioning model.

This repository currently contains the [product and architecture proposal](docs/product-architecture.md) and [source-backed research](wiki/research/index.md). No application services have been implemented yet.

## Research status

The supplied Notion pages were inspected in the logged-in browser; the research records only safe structural observations. The supplied AppFlowy guide returned a JavaScript shell to text readers; deployment findings use AppFlowy's official self-host repository and related documentation.
